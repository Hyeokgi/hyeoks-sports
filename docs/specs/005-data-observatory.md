# 데이터 관찰실: 계산에서 검증까지

## 목적
사용자가 승인한 방향(2026-10-15): 축구 정보를 복제하거나 글 수를 늘리기보다 HYEOKS가 계산한 전력과 저장한 예측을 실제 성적·결과와 비교한다. 예측 모델 계수·가중치는 바꾸지 않는다. 검색 승인이나 적중·수익을 약속하지 않는다.

## 공개 화면과 탐색
- 홈에 'HYEOKS 데이터 관찰실' 세 카드: 순위와 전력, 확률 성적표, 기존 리그별 무승부 비율.
- `/insights/rank-gap`: 자체 집계 성적 순위와 같은 현재 시즌 참가 팀들 사이의 Elo 순위를 비교한다. 과거 참가팀의 Elo 순위를 분모에 섞지 않는다. J1 시즌 구분 문제, K리그1 그룹·MLS 콘퍼런스 미분리, 수집 누락과 동률 정렬 한계를 고지한다. 차이는 가치·운·미래 순위의 증명이 아니다.
- `/insights/probability-audit`: 킥오프 전 저장된 유효한 확률과 확정 결과만으로 확률 구간의 실제 빈도를 평가한다. 경기별 최고확률 1순위 적중과 결과 종류별 확률 검증은 단위를 구분한다. 작은 표본·혼합 모델 기간·버전 미기록을 공개한다. 현재 모델로 과거 값을 채우지 않는다.
- 경기 분석 하위 메뉴에 '순위와 전력', 예측 기록 하위 메뉴에 '확률 성적표'. 모든 페이지 공통 꼬리말에 두 해설 링크.

## 빈 상태·오류·모바일
- 비교·검증에 부족한 자료는 부족하다고 표시한다. 없는 수치나 원인을 만들어 채우지 않는다.
- 각 페이지의 내부 편집 기준을 충족하기 전에는 noindex. 이는 Google의 공식 조건이 아니다. 사이트맵도 해당 기준을 충족할 때만 포함한다.
- 조회 실패는 내부 예외를 공개하지 않는 브랜드 503, 빈 데이터와 구분한다.
- 360px에서도 본문은 줄바꿈하고 넓은 비교표는 자체 수평 스크롤한다. 숫자만 색상으로 구분하지 않고 표 머리·부호 설명을 붙인다.

## 미래 예측 변화 기록
- 기존 prediction_snapshots는 경기당 마지막 예측 보존 용도로 그대로 둔다.
- 새 prediction_history는 배포 이후 실제로 캡처한 변화를 추가 전용으로 기록한다. 과거 캡처를 재구성하지 않는다.
- 저장 시각·킥오프·확률·근거와 허용된 수치 입력 맥락을 남긴다. 입력의 차이는 인과효과를 증명하지 않는다. 수집 규격 표시는 모델 검증 버전과 다르다.
- 표본이 쌓이기 전에는 결과 비교 페이지를 공개하지 않는다. 역사적 추적 자료가 없는 지난 경기로 초기 분량을 메우지 않는다.

## 측정·광고
- rank_gap_view, probability_audit_view를 기존 일별 집계에 추가한다. 개인 식별 정보는 새로 수집하지 않는다.
- 광고 자리·광고 스크립트는 추가하지 않는다. 계산·근거·제외 기준이 먼저 보이게 한다.
