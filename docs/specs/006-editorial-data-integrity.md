# 이야기 중심 개편 전 결과 데이터 신뢰성 수정

## 근거와 한계
2026-11-16 운영 페이지 `/insights/rank-gap`과 `/insights/draw-rates` 라리가가 집계 당일보다 미래인 2026-12-09까지 결과가 반영됐다고 표시했다. 코드에는 빈 CSV 점수를 `Number("") === 0`으로 받아들이는 경로와 미래 날짜의 결과를 배제하지 않는 경로가 있었다. 다만 현재 seed에는 2026-12-09 행이 없으며, 해당 운영 DB 행의 직접 유입 원인은 확정하지 못했다.

이 수정이 Google AdSense의 구체적인 거절 원인을 확인하거나 승인을 보장한다는 뜻은 아니다. Google의 거절 문구는 '가치가 별로 없는 콘텐츠'이며 개별 문제 페이지를 특정하지 않았다. 경기 수·글자 수·대기 일수는 공식 승인 기준으로 쓰지 않는다.

## 코드 변경
- 빈 값·공백·null·미정·음수·소수 점수는 결과로 변환하지 않고, 실제 0은 허용한다.
- 유효한 ISO 달력 날짜와 명시적 시간대 시각을 검사한다. 날짜만 있는 기록은 UTC 오늘까지, 시각이 있으면 기준 시각까지 허용한다. 이는 날짜만 있는 기록의 실제 종료 시각을 증명하지 않는다.
- FotMob 종료 결과·football-data 백필에서 검증하고, DB 읽기·순위표·비율 집계에서도 재검사한다. 미래 예정 일정은 유지한다.
- 미래·비정상·불명 날짜가 붙은 저장 Elo는 표시에서 제외한다. 기존 Elo나 예측 입력을 자동 복구한 것으로 표시하지 않는다.
- '최근 완료 3시즌'을 '최근 과거 구간 저장분'으로 고쳐 포함 구간 수와 자료 없는 구간을 표시한다. 표본 수가 충분해도 수집 완전성이 증명되는 것은 아니다.
- 현재 시즌 '전체 참가 팀' 대신 저장 결과에 등장한 팀 집합임을 명확히 한다. 순위 차이 페이지는 원인을 증명하지 않으므로 제목을 '순위와 Elo는 얼마나 다를까?'로 맞추고 Elo 점수도 표시한다.
- 조건부 noindex인 `/matches`, `/ratings`, `/insights/draw-rates`를 고정 사이트맵 목록에서 빼고 렌더러와 같은 조건으로 넣는다.

## 변경하지 않은 것
모델 계수·가중치, 원본 DB 행, `prediction_snapshots`, `prediction_history`, 과거 사전 예측, 블로그 글, 광고 스크립트, 애드센스 제출 상태를 변경하지 않는다.

## 운영 자료 복구는 별도 단계
읽기 필터는 저장된 행의 영구 격리가 아니다. 날짜가 지나면 미래 행도 과거가 되므로 운영 원본을 조사해야 한다. 배포 전 고정 시각의 백업과 의심 행·원천 경기 ID/날짜/종료 상태 확인, 순수 재계산 결과와 기존 파생값 차이 검토가 필요하다. 기존 `admin/sync?recompute=1`은 수집·정산·스냅샷·별칭 Elo 삭제도 실행하므로 진단용으로 무작정 호출하지 않는다. 확인 후 승인받은 파생 테이블 복구만 수행하고 사전 예측 기록은 소급 재작성하지 않는다.

## 콘텐츠 방향
사용자는 축구 통계 이야기를 본체로 하고 토토 분석을 부가 기능으로 두는 방향을 제안했다. 이번 패치는 데이터 정합성 수정이며 홈을 이야기 아카이브로 전환한 구현은 아니다. 후속 개편은 질문 → 검증된 사례 → 비교·그래프 → 해석 → 한계의 고유 콘텐츠를 중심으로 설계한다. 토토 기능을 심사자에게만 숨기거나 다른 내용을 보여주는 방식은 사용하지 않는다.
