# 001. 광고·스폰서 자리 (초안)

> 작성: 2026-09-26, 사용자 요청으로 AI 브라우저(Aside)가 초안 작성. **Codex가 모양·위치를 검토해 확정**한 뒤 Claude가 구현한다(COLLAB 1장 역할).

## 1. 목적

스폰서·광고를 받을 자리를 미리 마련한다. 광고주가 생기기 전까지는 파트너를 구하는 "하우스 광고"를 보여준다.
광고 수익보다 **신뢰**가 우선이다. 분석 화면을 가리거나 확률처럼 보이게 하지 않는다.

## 2. 위치 (제안)

| 슬롯 id | 화면 | 위치 | 비고 |
|---|---|---|---|
| `matches-bottom` | 앱 경기 탭 | 경기 목록 아래 | 조합·확률 위에는 두지 않는다 |
| `info-bottom` | 앱 정보 탭 | 고지 문구 위 | |
| `round-bottom` | `/round/{회차}` | 본문 카드 아래 | **`/draft`, `data.json`에는 넣지 않는다** |

블로그는 이미 운영 중이다(사이드바 위젯, 회차 글 하단 SPONSOR 칸).

## 3. 구성

- 상단 라벨 `SPONSOR` (광고임을 항상 표기)
- 제목 한 줄 + 설명 한 줄 + 링크 한 개
- 하우스 광고 문구
  - "이 자리의 파트너를 찾습니다"
  - "스포츠 미디어·데이터 서비스·축구 용품 브랜드를 위한 자리입니다. 불법 도박·사설 토토 광고는 받지 않습니다."
  - 링크 "제휴·광고 안내 →" https://blog.naver.com/beauty017/224423344071
- 실제 광고 링크는 `rel="sponsored noopener"`

## 4. 상태

- 광고주 없음: 하우스 광고 표시(숨기지 않음, 사용자 요청: 자리를 먼저 마련). Codex가 숨김이 낫다고 보면 이 항목을 고친다.
- 광고 문구는 KV(`ad_slots`)에 두고 관리자 API로 바꾼다. `until`이 지나면 하우스 광고로 돌아간다.

## 5. 모바일(360px)

- 폭 100%, 최소 높이 100px로 고정해 레이아웃이 밀리지 않게 한다(CLS 방지).
- 기존 카드 스타일(점선 테두리)로 분석 카드와 구분한다.

## 6. 측정 이벤트

- `ad_view`(슬롯 id별), `ad_click`(슬롯 id별). `src/lib/usage.ts` 허용 목록에 추가.

## 7. 금지

- 불법 도박, 사설 토토, 해외 베팅 사이트, 적중 보장 유료 픽 광고와 링크 금지
- 예측 확률·픽 영역 안이나 사이에 광고를 넣지 않는다
