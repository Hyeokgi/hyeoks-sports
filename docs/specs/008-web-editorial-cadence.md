# HYEOKS 웹 데이터 스토리

- KST 기준 3일에 한 편 목표. 블로그와 편성은 공유하되 웹 공개 이력·링크는 별도. 최초 목표는 2026-12-01 07:30 KST. 지연되면 실제 공개일에서부터 3일 후로 계산하고 기사를 한꺼번에 공개하지 않는다. 이후 작업의 발행 날짜는 배포 직전에 확인한다.
- 경기 프리뷰: 전력 맥락과 동일 비교 구간, 관전 포인트. 경기 리뷰: 실제 장면과 팀의 평소 기준, 지표의 한계. 데이터 기사: 원자료 고정 스냅샷, 산식, 분자·분모, 반례와 한계. 규정 기사: 공식 규정과 실제 사례.
- 첫 글 draw-first-rank-audit: 킥오프 전 기록 100행, 기간과 표본 선정 범위, 순위별 비교표, 재계산 자료 JSON. 기존 분석·회차 로직 변경 없음.
- 공개 전: npm ci, npm run typecheck, npm test, npm run build:client. 예약 날짜 전 기사·근거 파일 404, 홈/아카이브/사이트맵 제외. 태그·URL·표시 날짜는 공개 시점에 확인.
- 공개 후: 글 200 및 canonical, 홈/아카이브 링크와 사이트맵, 모바일 표 및 퀴즈, 스냅샷 200 및 noindex. 공개 상태를 확인해야 편성표를 갱신한다.
- 이 변경은 소스 배포를 필요로 한다. 준비 루틴이 GitHub 병합·운영 배포·AdSense 재검토를 자동 실행하지 않는다.
