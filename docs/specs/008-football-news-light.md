# 008 · 최근 축구 이야기 우선, 밝은 데이터 매거진

## 목적과 편집 순서

홈의 첫 질문을 ‘확률을 어떻게 검증하는가’에서 ‘최근 축구에서 무슨 재미있는 일이 있었나’로 바꾼다. 승인 보장이나 AdSense 공식 최소 기사 수를 주장하지 않는다.

1. 실제 최근 경기의 흥미로운 숫자와 완결된 기사
2. 그 숫자를 읽는 방법과 방법론
3. 확률 기록·승무패 도구·토토 관련 기능

기존 도구와 옛 링크는 유지하되 주인공이 아니라 선택적인 다음 경로로 배치한다. 신규 기사 앞부분에 구매·조합·예측 CTA를 넣지 않는다. 기본 순서는 실제 경기 → 하나의 발견 → 직접 계산 → 해석 → 짧은 한계 → 원자료/고정 스냅샷이다. 표제마다 ‘질문/관찰/한계’를 반복하지 않는다.

## 콘텐츠 계약

- 구현: `src/lib/footballNews.ts`. `Story`는 type-only import로 순환 런타임 의존을 방지한다.
- `FOOTBALL_NEWS`: Story 기본 필드 + kind=`match-report`, 한국시간 경기일 `eventDate`, `featureStat.value/label`, `topic`, `sources` URL 배열.
- `FOOTBALL_NEWS_SNAPSHOTS`: slug별 고정 JSON 자료. `asOf`, `scope`, `sources`, 경기일/한국시간, 원자료, 산식, 한계를 포함한다.
- 발행일 2026-11-20, 자료 확인 기준 2026-11-20T13:30:46.941Z. 본문·JSON은 실시간 조회와 분리한다.
- 신규 기사 3편: 한국–카타르 슈팅(20:2), 노르웨이–덴마크 득점 시계(0:2→3:2), 공식 8경기의 골 집중도(43.5%).
- 한국전 박스 터치는 검색 발췌와 원문이 달라 제외한다. 점수만 내부 `/performance/data.json`으로 교차 확인했고, 슈팅 통계까지 내부 자료에서 확인했다고 쓰지 않는다.
- UEFA의 현지 11월 17일 편성은 KST 11월 18일 새벽이다. 한국–카타르는 KST 11월 17일 23시다. 발행일과 경기일을 별도로 표시한다.
- 신규 스냅샷 라우트: `/stories/{slug}/snapshot.json`. HTML 상단 링크와 Article citation/isBasedOn도 해당 slug에 맞춰 연결한다. 라리가 기존 스냅샷으로 잘못 연결하지 않는다.
- 자료는 분자·분모·산식을 보존한다. 23골 기사는 8대진 결과 전체를 공개해 합계를 다시 셀 수 있다.
- AI 편집 보조와 작성 주체 고지는 기존 중앙 기사 템플릿에 유지한다. 독립 전문가 검토/현장 취재를 꾸며내지 않는다. 기존 공통 이용 고지도 유지한다.

## 화면 구성과 스타일

홈: 밝은 소개 → 대표 경기 이야기 → 나머지 최신 기사 → 방법론 읽을거리 → 선택적 데이터/도구. 아카이브에서도 경기 기사를 먼저, 방법론을 별도 영역으로 구분한다. 본문은 자연스러운 소제목, 넉넉한 줄 간격, 한 화면에 하나의 주요 숫자가 읽히는 구성이다.

팔레트 권장값:
- 배경 아이보리 `#FAF8F1`, 카드 `#FFFFFF`, 보조 면 `#F0F5EB`
- 본문 진녹색 `#193D32`, 주요 링크 녹색 `#246B50`
- 강조 코랄 `#D96B52`, 코랄 면 `#FFF0E9`, 경계 `#DDE5D8`
- 코랄은 수치 장식과 면에 사용하고 작은 본문 글자는 진녹색으로 유지한다. 실제 대비는 배포 전 검사한다.

사진·로고·국기 없이 원자료 숫자로만 그림을 만든다. 각 기사에는 HTML figure 하나와 figcaption, 읽을 수 있는 텍스트 수치가 있다. 외부 CDN·이미지 요청·본문 인라인 CSS는 없다.

CSS 연결점: `.news-stat-figure`, `.news-stat-row`, `.news-goal-events`. 텍스트를 숨기고 색만으로 구분하지 않는다. 360px에서는 카드 한 열, 긴 국가명/출처 URL 줄바꿈, figure 행도 필요하면 세로 배치한다. 고정 최소 너비로 가로 스크롤을 만들지 않는다. 키보드 링크 포커스가 보여야 한다.

## 빈 상태·오류·신선도

- 확인된 새 기사가 없으면 마지막 발행일을 유지하고 ‘최근 발행한 이야기’로 표기한다. ‘오늘 경기’, ‘방금 업데이트’처럼 시간이 지나면 거짓이 되는 표시는 하지 않는다.
- 발행일만 바꿔 오래된 결과를 새 기사처럼 보이게 하지 않는다. 경기 날짜와 자료 확인 날짜를 숨기지 않는다.
- 새로운 자료가 없을 때 가상 경기, 추정 스코어, 미확인 xG, 통계 없는 대체 기사를 채워 넣지 않는다.
- 동적 경기 API 실패가 고정 편집 기사까지 없애지 않게 한다. JSON 라우트에서 미등록 slug는 404, 다른 기사 자료로 fallback하지 않는다.
- 정정은 수정 날짜·이유·범위를 기록하고 원자료 변경 여부를 밝힌다. 라이브 결과로 기존 논증을 조용히 덮어쓰지 않는다.

## 측정과 광고

기존 `stories_view`, `story_view`를 재사용한다. 추가 이벤트나 개인 데이터 수집은 만들지 않는다. 광고 스크립트 비활성 상태를 유지하며 신규 광고/스폰서가 없으면 자리를 숨긴다. 기존 사이트의 정책·연락처·책임 있는 이용 안내를 지우지 않는다.

## 역할과 검증

이 작업의 쓰기 범위는 신규 `src/lib/footballNews.ts`, `tests/footballNews.test.ts`, 이 명세뿐이다. 홈·stories.ts·CSS·네비게이션·라우터는 통합 담당자가 연결한다.

회귀 검사는 한국전의 1/20=5%, 9/20=45%, 노르웨이 득점 순서와 2/3=66.7%, 공식 8경기의 합계 23골·10/23=43.5%·전체 평균 2.88골·나머지 평균 2.17골을 재계산한다. 중복 slug, 출처 직접 링크, 기사-스냅샷 일대일 대응, 날짜/시차, 본문 길이, figure 접근성, 앞부분 축구 우선도 검사한다. 통합 담당자는 기존 전체 기사 수 검사와 JSON-LD·라우팅 검사, 360px 시각 점검 및 전체 타입/테스트/빌드를 수행한다.
