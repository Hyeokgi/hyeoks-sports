Elo 레이팅: 기대 점수와 승리 확률은 다릅니다

HYEOKS 운영자 · 수정 2026-10-11

Elo는 예상했던 결과와 실제 결과의 차이로 팀의 점수를 갱신하는 방식입니다. 핵심은 기대 점수를 곧바로 승리 확률로 읽지 않는 것입니다. 축구에서는 무승부에도 반 점을 주므로 두 개념이 다릅니다.

점수 차를 기대 점수로 바꾸기

홈 보정을 포함한 점수 차를 d라고 하면 HYEOKS 클럽 Elo의 기대 점수 E는 1 / (1 + 10^(-d / 400))입니다. 결과 점수 S는 승리 1, 무승부 0.5, 패배 0입니다. 아래는 실제 팀 데이터가 아닌 공식 대입 예시입니다.

높은 쪽의 기대 점수, 0~1 값을 백분율로 표시
보정 후 점수 차E (÷400)
100점64.0%
200점76.0%
400점90.9%

E=0.60은 ‘60% 승리’가 아닙니다. 승/무/패가 50/20/30%인 경우에도, 40/40/20%인 경우에도 P(승)+0.5×P(무)=0.60입니다. 기대 점수 하나로 세 결과 확률을 유일하게 정할 수 없습니다.

한 경기가 점수를 얼마나 바꾸나요

갱신식은 새 점수 = 기존 점수 + K×(S−E)입니다. K=32, E=0.60인 설명용 팀은 승리하면 +12.8점, 무승부면 −3.2점, 패배면 −19.2점입니다. 승리 예상이 높았던 팀도 무승부로 점수를 잃을 수 있습니다. K는 민감도이며 경기 결과의 확실성을 뜻하지 않습니다.

FIFA 랭킹과 같은 수치인가요

FIFA 공식 절차에 따르면 남자 랭킹은 2018년 8월 SUM 방식으로 전환해 이전 점수에 경기별 증감을 반영합니다. Elo와 기본 발상은 비슷해도 경기 가중치와 세부 규칙이 다릅니다. HYEOKS 클럽 점수를 FIFA 순위와 직접 비교할 수 없습니다. 현재 국가별 순위나 라이브 발표 일정은 이 글에서 단정하지 않습니다.

HYEOKS 실제 구현

클럽 Elo 코드를 대조하면 K_FACTOR=32, 기본 HOME_ADV=60이며 MLS는 85, 라리가는 105입니다. 새 팀은 1500에서 시작하고 시즌 경계에서는 1500과의 차이를 25% 줄입니다. 이는 이 서비스의 구현값이며 모든 Elo 시스템에 공통인 상수가 아닙니다.

홈 보정은 실제 점수 차에 더하는 모델 입력입니다. 예를 들어 동점 팀끼리 기본 홈 보정 60을 쓰면 E≈58.5%지만, 홈승 확률이 58.5%라는 뜻은 아닙니다. HYEOKS의 최종 3-way 확률은 무승부 처리와 다른 성분·시장 결합을 거칩니다. 국가대표 Elo는 별도 구현입니다.

  • 클럽 모델·시장 배당·국가대표 모델·근거 없음의 basis를 구분합니다.
